The browser build of CamCraft is **not part of this copy of the site**.

On a release, the release workflow builds CamCraft to run in a browser
and puts it at this address, in place of this page. You see
this page instead when that build failed for this release (the release's
workflow run names it), or when the site was built without it, as a local
preview is.

Use the [desktop downloads](https://github.com/NeoTech/Camcraft/releases)
meanwhile; they have everything the browser build has, and more.
