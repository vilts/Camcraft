Start with [model import and stock](@/guide/getting-started/first-run.md#a-first-toolpath).
Read [Units and coordinates](@/guide/reference/units-and-coordinates.md)
before importing a model whose file does not state its unit.

[Setups](@/guide/set-up/setups.md) explains how the stock, machine and post
belong to each setup. Place its [work offset](@/guide/set-up/setups.md#work-offset),
then define the [workholding](@/guide/set-up/workholding.md) and
[tools](@/guide/set-up/tools.md). For a second setup, read how to
[carry stock forward](@/guide/set-up/setups.md#carrying-stock-to-the-next-setup).
