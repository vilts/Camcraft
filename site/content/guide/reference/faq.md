## CamCraft will not start on Windows, or my PC freezes. What should I try?

Start with [Windows troubleshooting](@/guide/reference/windows-troubleshooting.md).
It explains graphics backend options, checks for a freezing PC, and what to
include in a problem report. If CamCraft shows a refusal message, look it up
in [Troubleshooting](@/guide/reference/troubleshooting.md).
