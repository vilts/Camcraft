Start here: [Install](@/guide/getting-started/install.md) → [First run](@/guide/getting-started/first-run.md) → [Setups](@/guide/set-up/setups.md) → [Operations](@/guide/operations/_index.md) → [Check](@/guide/check-and-post/_index.md) → [Post](@/guide/check-and-post/posting.md).

The sections below follow a job from the first model to the NC program.
Use the guide navigation to find a stage of the job or a reference page.

The [CAM fundamentals](@/guide/fundamentals/_index.md) section explains the
machining principles behind these steps: feeds and speeds, tools, strategy,
rigidity, chips, finish, proving out and posts.

For task recipes (facing, two-setup squaring, pockets, holes, lathe,
re-posting) see [Common workflows](@/guide/getting-started/workflows.md).

[Tools and tool libraries](@/guide/set-up/tools.md) covers tool creation, holders,
modular bodies, controller numbers, and library import and export.

The [glossary](@/guide/reference/glossary.md) defines the terms CamCraft uses, such as
setup, work offset, stale, gouge and refusal, and links each to its page.

The [Multi-axis](@/guide/multi-axis/_index.md) section covers indexed 3+1
and 3+2, continuous 4-axis, simultaneous 5-axis, TCP and their checks.

Stuck on a message? See [Troubleshooting](@/guide/reference/troubleshooting.md).
