The browser version is an early one. It cannot open or save files yet (models, projects and programs), simulation playback does not work in it yet, it does not use the newer WebGPU graphics, and views that need more graphics features than the browser offers say so instead of drawing. For real work, use the desktop downloads (#31 tracks what is still missing).
